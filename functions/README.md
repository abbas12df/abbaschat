# Cloud Functions — إرسال الإشعارات من الخادم

هذا المجلد ينقل إرسال إشعارات Push إلى خوادم Firebase، بحيث لا يحتاج التطبيق
لأي مفتاح سري. حساب الخدمة يبقى على خوادم Google فقط.

## المتطلبات

1. خطة Firebase من نوع **Blaze** (الدفع حسب الاستخدام — الدوال ضمن الحصة
   المجانية السخية، 2 مليون استدعاء شهرياً مجاناً).
2. تثبيت أدوات Firebase:
   ```bash
   npm install -g firebase-tools
   firebase login
   ```

## النشر

من جذر المشروع:

```bash
cd functions
npm install
cd ..
firebase deploy --only functions
```

بعد نجاح النشر، التطبيق سيرسل الإشعارات تلقائياً عبر الدالة السحابية الآمنة.

## بعد النشر (مهم جداً للأمان)

1. تأكد أن الإشعارات تصل بنجاح من التطبيق.
2. احذف `lib/core/security/secure_service_account.dart` والمسار الاحتياطي
   (LEGACY FALLBACK) من `push_notification_service.dart`.
3. **أبطل مفتاح حساب الخدمة القديم** لأنه كان مدمجاً في التطبيق ومعرّضاً:
   - Google Cloud Console ← IAM & Admin ← Service Accounts
   - اختر الحساب ← Keys ← احذف المفتاح القديم
4. راجع استخدام حسابات الخدمة من Cloud Console للتأكد من عدم وجود استخدام مشبوه سابق.

## ملاحظات أمان الدالة

- ترفض أي طلب من مستخدم غير مسجل الدخول (`unauthenticated`).
- تحقق من صحة صيغة رمز FCM وحدود أطوال النصوص.
- حد معدل: 60 إشعاراً في الدقيقة لكل مستخدم.
- لا تسرّب تفاصيل الأخطاء الداخلية للمتصل.
